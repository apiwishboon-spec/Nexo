# Nexo v2.2.3

Fixes the macOS self-update flow.

## What's fixed
- macOS updates no longer fail silently. If Nexo is running from a Gatekeeper
  translocated path or a read-only location (e.g. launched straight from the
  download), the app now shows a clear message telling you to move Nexo to
  /Applications and relaunch before updating.
- The update button properly surfaces download/install errors instead of
  failing silently.
- When an automatic update can't run, the download is revealed in Finder with
  instructions to finish manually.

## Tested on real hardware
- Native unit tests: 24/24 PASSED.
