# Nexo v2.2.1

Small follow-up to v2.2.0.

## What's new
- Home character option #2 is now an **8-bit owl** (it replaced the glasses
  kid; classier on a 240x135 panel) alongside the orange cat.
- Orange tabby palette applied to the cat.
- Memo list now shows its current index (`n / total`) so you can see when more
  memos are above/below the visible window.
- BLE multi-central fix: a second companion app can now connect to the same
  device (advertising restarts on connect).

## Tested on real hardware
- Built and flashed to a **M5Stack Cardputer-Adv**; voice memos and character
  selection verified.
- Native unit tests: 24/24 PASSED.
