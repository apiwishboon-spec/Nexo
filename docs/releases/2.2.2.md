# Nexo v2.2.2

Fixes for v2.2.1.

## What's fixed
- Memo list rows are shorter (18px) so all 4 visible rows fit above the footer
  without being cut off at the bottom of the screen.
- Audio task keeps feeding the decoder even when nothing is actively playing,
  preventing I2S DMA underruns after a memo recording handback.
- Memo footer shows current index (`n/total`) so you can see when more memos
  are above/below the visible window.

## Tested on real hardware
- Built and flashed to a **M5Stack Cardputer-Adv**; voice memos and MP3 playback
  verified.
- Native unit tests: 24/24 PASSED.
