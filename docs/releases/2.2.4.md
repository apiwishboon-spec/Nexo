# Nexo v2.2.4

Animation fix.

## What's fixed
- The Home character (cat/owl) no longer makes the whole screen flash. The panel
  only repaints when the animation pose actually changes (~2x/second max) instead
  of redrawing everything every 400 ms.

## Tested on real hardware
- Built and flashed to a **M5Stack Cardputer-Adv**; verified the character
  animates smoothly without screen flash.
- Native unit tests: 24/24 PASSED.
