# Nexo v2.2.9

More reliable Wi-Fi AP connection and a small navigation tidy-up.

## What's fixed
- **Voice Memos connects more reliably.** The app now reuses the same
  AP-join/verification logic as the firmware updater, so it auto-joins when
  possible and fails fast with a clear message if it can't reach the device.
- **Memos button moved earlier in the Cardputer home menu** (now appears before
  Settings as requested).
