# Nexo v2.2.0

A firmware release: **voice memos** and a **selectable 8-bit character** for the
Home pane.

## What's new

### Voice memos
- New **Memos** screen on the device. Press **R** to record (the header shows a
  blinking indicator and a `mm:ss` timer), **ENTER** to stop & save, **ENTER** to
  play/pause, **DEL** to erase.
- Recordings are written as 16 kHz mono WAV files to `/memos` on the microSD card,
  so you can pull them off on a computer too.
- Recording parks the music decoder and hands the I2S bus to the microphone, then
  restores the speaker path and clears memo state when playback ends — a memo
  never auto-advances your music queue.

### Home character
- The Home left pane can now show a little **8-bit character**: an orange **cat**
  or an **owl**, both animated (bobbing every few seconds with a blink).
- Pick it in **Settings → Home character**; the choice is saved to preferences.

### Under the hood
- Firmware bumped to `2.2.0`.
- New audio API in `hw/audio` (`memoBegin/Scan/RecordStart/RecordStop/Play/Delete/…`).
- Preview/emulator stubs implement the memo API so the whole flow is testable
  without hardware.

## Tested on real hardware
- Built and flashed to a real **M5Stack Cardputer-Adv** (`pio run -e m5stack-cardputer`, SUCCESS).
- Verified on-device: boot, Home, character selection, voice-memo record → save →
  play → erase, and music playback after memos.
- Native unit tests: **24/24 PASSED**.
- WASM emulator + preview renders: OK.
