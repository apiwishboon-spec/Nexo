# Nexo v2.1.0

An app-focused release: Nexo now **updates itself**.

> The firmware is unchanged from v2.0.0 (no reflash needed). Only the companion
> app was updated.

## What's new

### In-app updates
- The app checks GitHub Releases on launch (and on demand via **About → App
  updates**) and tells you when a newer version is available.
- **Android:** one-tap download of `Nexo-android-release.apk` and hand-off to the
  system package installer. The first time, allow *Install unknown apps* for Nexo.
- **macOS:** the App Sandbox is now disabled so Nexo can download
  `Nexo-macos-release.zip`, swap `/Applications/Nexo.app` and relaunch itself in
  one click. If the app is running from a read-only or translocated location, the
  download is revealed in Finder instead.
- Release notes are shown inline, with a link to the release page. Auto-check can
  be turned off.

### Under the hood
- New dependencies: `package_info_plus`, `path_provider`, `url_launcher`,
  `pub_semver`.
- Added unit tests for release parsing and version comparison.

## Downloads
- `Nexo-android-release.apk` — Android app (arm64).
- `Nexo-macos-release.zip` — macOS app.
- `Nexo-m5stack-cardputer.bin` — firmware image (same as v2.0.0).
- `SHA256SUMS` — checksums for the above.
