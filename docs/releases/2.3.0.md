# Nexo v2.3.0

Faster, more stable AP transfers with safer OTA.

## What's improved
- **Tuned Wi-Fi AP.** Fixed channel 6, `maxConn=1`, and a modest TX power bump for more reliable uploads over the device AP.
- **OTA hardening.** Added a 15s idle timeout during firmware upload, always abort on errors, and clean up BLE state. If the transfer stalls or fails, the device won't apply a half-written image.
- **Less radio contention.** BLE pauses (advertising stopped and active connections dropped) during bulk OTA transfers to free up Wi-Fi airtime.
- **Faster music uploads.** Music import now buffers writes to the SD card in 16KB chunks, reducing stalls on slower cards.
