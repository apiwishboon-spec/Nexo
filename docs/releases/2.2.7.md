# Nexo v2.2.7

Voice Memos is now its own tab in the app.

## What's new
- **Voice Memos tab.** The Voice Memos screen moved from the Device tab into a
  dedicated tab in the main navigation (so it's always just one tap away). It
  still works over the device's Wi-Fi AP to play, save/share, delete and
  transcribe recordings from the SD card.
